recipe: @sync-goose-sessions

How it works

  • 1
    Sessions live in a SQLite DB (sessions.db) that can’t be real-time synced across machines.
  • 2
    We take a snapshot with scripts/sync-sessions.sh and push it to GitHub.
  • 3
    Restore auto-remaps working_dir to the local paths so sessions open cleanly.

Troubleshooting ▾
"Invalid directory path"

Means the session has a working_dir from the other machine (a foreign path). Just run restore — it auto-fixes this via remap, rewriting paths to your local ones.

Never rsync the workspace

🔒

The workspace is owned by mutagen. Don’t rsync it manually — you’ll fight mutagen and corrupt the sync. Only move sessions through the snapshot / restore scripts above.
