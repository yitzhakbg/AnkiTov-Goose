# openrouter tts audiobook hebrew gemini
OpenRouter TTS audiobook pipeline (verified end-to-end 2026-10-14, "Across So Many Seas" Hebrew audiobook): OpenRouter has a dedicated POST /api/v1/audio/speech endpoint (OpenAI-speech-compatible, raw audio bytes, NOT chat/completions). Discover TTS models: GET /api/v1/models?output_modalities=speech (35 models; pricing mostly per INPUT character: google/gemini-3.8-flash-tts + -flash-lite-tts $0.50/1M chars, elevenlabs flash v2.5 $20/1M). Gemini TTS quirks: response_format must be "pcm" (mp3 → 400), output = raw 24kHz mono 16-bit PCM → wrap with wave module; voice = Gemini voice names (Kore, Puck, Zephyr… 30); instructions param = delivery style; 32K token context → chunk ~3800 chars at paragraph/sentence boundaries, concatenate with ~0.35s silence. Hebrew (he-IL) verified good on Gemini tiers + ElevenLabs. Pipeline: parse doc → sections.json → 2 parity-split nohup workers → per-section WAV → afconvert -f m4af -d aac -b 64000 -c 1 → m4a. GOTCHA: goose shell tool kills background children if the launching command hits output-drain timeout — launch from a clean fast-exiting command. 198K chars = 4h51m audio ≈ $0.10, ~25 min with 2 workers. Output: ~/Music/AcrossSoManySeas-HE/ (66 m4a + playlist.m3u8 + wav/ masters 0.84GB).
