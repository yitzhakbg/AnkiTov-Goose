# headroom compression gotcha
Headroom ccr compressor gotcha (2026-11-08): large shell tool outputs can be replaced by a marker like <<ccr:hash,string,N.NKB>> in the returned output; headroom_retrieve(hash) FAILS to unwrap ccr markers (returns the marker itself, original_content identical). Workaround: re-read in smaller chunks (e.g. `sed -n 'a,bp' file | cut -c1-160`) which pass under the compression threshold; small outputs (<~300B) always pass through raw.
